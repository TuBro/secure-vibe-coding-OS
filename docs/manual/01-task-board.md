# 01 — Task Board

**Section:** Tasks  
**Tool:** Task Board — To Do / In Progress / Done  
**Location:** Dashboard → scroll to Task Board

---

> **Remember:** You are doing this manually first so you understand it fully. Once you can run this step without thinking, that is when we automate it.

---

## Purpose

The Task Board is where all work gets tracked at a glance. Every task the team is carrying — whether it is a follow-up, a build item, an internal action, or a reminder — lives here.

If you agreed to do something, it goes on the board. If the team needs to see where something is at, it goes on the board.

If it is not on the board, no one knows it exists.

---

## The Three Columns

| Column | Meaning |
|--------|---------|
| **To Do** | Task created — no one has started it yet |
| **In Progress** | Someone is actively working on it right now |
| **Done** | Task is complete |

---

## How To Add a Task

1. Go to Dashboard → scroll to **Task Board**
2. Click **+ Add Task**
3. Fill in the details:
   - **Task title** — one clear sentence describing what needs to be done (required)
   - **Notes** — any extra context the team needs (optional)
4. Click **Add**
5. The task card appears in the **To Do** column instantly

---

## How To Write a Good Task Title

A good task title tells anyone on the team exactly what needs to be done without asking for more context.

| Weak | Strong |
|------|--------|
| "Follow up" | "Follow up with Mark — Tu80 proposal sent Monday" |
| "Fix the thing" | "Fix Add Lead button not saving on mobile" |
| "Send it" | "Send March invoice to Tangaroa Energy client" |

One sentence. Specific. Actionable.

---

## How To Move a Task Forward

As work progresses, drag the card to the next column:

1. Click and hold the task card
2. Drag it across to **In Progress** or **Done**
3. Release — it saves instantly

---

## How To Delete a Task

1. Find the task card
2. Click the **trash icon** on the card
3. Confirm the deletion

> **Warning:** Deletions are permanent. There is no undo.

---

## What Good Looks Like

- Every agreed action goes onto the board the moment it is agreed — not later
- **To Do** column is reviewed every Monday morning — anything stale gets reassigned or dropped
- No task sits in **In Progress** for more than 3 days without an update
- **Done** column is cleared at the end of each week
- The board is never empty during an active week — if it is, tasks are being held in heads instead of here

---

## What To Automate Later

Once the team is using the Task Board consistently, these steps are candidates for automation:

- Tasks auto-created from Te Ra voice notes when an action item is detected
- Reminder sent when a task has been In Progress for more than 3 days without moving
- Weekly Done summary delivered to the team every Friday

You will know it is time to automate when the same type of task is created manually every single week from the same source.
